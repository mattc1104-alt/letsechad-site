One-time setup (30–45 minutes)

Step 1

Create the GitHub repo

  1. Go to github.com and sign in
  2. Click New repository (the + icon, top right)
  3. Name it letsechad-site
  4. Set it to Public (Decap CMS free tier requires public repos)
  5. Don't add README or .gitignore — leave it empty
  6. Click Create repository
Step 2

Edit admin/config.yml — replace YOUR_GITHUB_USERNAME

Open admin/config.yml and change the first two lines to match your actual GitHub username and repo name:

backend:
  name: github
  repo: YOUR_ACTUAL_USERNAME/letsechad-site
  branch: main

Save the file.

Step 3

Push the files to GitHub

If you have Git installed, open Terminal/Command Prompt in the site folder and run:

git init
git add .
git commit -m "Initial site with CMS"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/letsechad-site.git
git push -u origin main

Or use GitHub Desktop (easier): File → Add Local Repository → drag the folder in → Publish Repository.

Step 4

Connect GitHub to Netlify

  1. Log into netlify.com
  2. Go to Sites → find your letsechad site → Site configuration
  3. Under Build & deploy → Repository, click Link to a repository
  4. Choose GitHub → authorize → select letsechad-site
  5. Build command: leave blank. Publish directory: . (a single dot)
  6. Click Deploy site
After this, every time you push to GitHub (or CMS publishes), Netlify auto-deploys. You never drag-and-drop again.
Step 5

Set up GitHub OAuth for the CMS editor

Decap CMS needs permission to write to your repo. Do this once:

  1. Go to github.com → Settings → Developer settings → OAuth Apps → New OAuth App
  2. Fill in:
    • Application name: L'ets Echad CMS
    • Homepage URL: https://letsechad.netlify.app
    • Authorization callback URL: https://api.netlify.com/auth/done
  3. Click Register application
  4. Copy the Client ID and generate a Client Secret

Then in Netlify:

  1. Site configuration → Access control → OAuth → Install provider
  2. Provider: GitHub. Paste your Client ID and Client Secret.
  3. Save.
Step 6

Test the CMS editor

Go to: https://letsechad.netlify.app/admin

Click Login with GitHub. You should see a Decap CMS dashboard with a "Teachings" collection.

If you get a login error, double-check the OAuth callback URL in Step 5 — it must be exactly https://api.netlify.com/auth/done.

How to publish a new teaching

Publishing workflow

In the CMS editor

  1. Go to letsechad.netlify.app/admin → Teachings → New Teaching
  2. Fill in: Title, Parashah Tag, Book, Scripture References, Card Summary, Full Teaching body
  3. Click Publish
  4. Netlify deploys in ~30 seconds — the Markdown file is saved to your teachings/ folder in GitHub
Important: The CMS saves a Markdown file. It does not automatically create the HTML page visitors read. See "Creating the teaching HTML page" below.

Creating the teaching HTML page

When you publish a new teaching through the CMS, a .md file gets saved to teachings/. You also need to create a matching .html page in that same folder so visitors can read the full teaching.

Use the included teaching-template.html. Duplicate it, rename it to match your teaching slug (e.g. teachings/parshat-vayera.html), then replace these placeholders:

  • TEACHING_TITLE — full title
  • TEACHING_TAG — e.g. Shemot · Va'era
  • TEACHING_REFS — scripture references
  • TEACHING_BODY — the teaching content as HTML paragraphs

Then add a card to teachings.html pointing to that page. See the existing card format.
